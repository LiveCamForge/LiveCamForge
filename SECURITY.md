# Security Policy

## Supported versions

Security fixes are provided for the latest stable LiveCamForge release.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Pre-1.0 development releases | No |

## Reporting a vulnerability

Please do **not** publish sensitive vulnerability details in a normal GitHub Issue, Discussion or public pull request.

Preferred reporting options:

1. Use GitHub's private vulnerability reporting / Security Advisory workflow for the LiveCamForge repository when available.
2. If private GitHub reporting is unavailable, contact `contact@livecamforge.com` and clearly mark the message as a security report.

Include enough information to reproduce and assess the issue, such as the affected version, deployment context, relevant request/response behavior and a minimal proof of concept. Do not include real provider credentials, affiliate tokens or personal data.

We will review credible reports, coordinate a fix when needed and publish security information after users have had a reasonable opportunity to update.

This file covers vulnerability disclosure for the LiveCamForge project itself. Deployment hardening, permissions, HTTPS, Admin security, postback secrets and production recommendations are documented in [docs/SECURITY.md](docs/SECURITY.md).
